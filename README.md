# Unfluke App

## Setup Instructions

1. Install dependencies:
```bash
   npm install
   # or
   yarn install
```

2. Generate native folders:
```bash
   npx expo prebuild
```

3. Run the app:
```bash
   # iOS
   npx expo run:ios
   
   # Android
   npx expo run:android
```

## Requirements
- Node.js 16+
- Expo CLI
- Xcode (for iOS)
- Android Studio (for Android)
